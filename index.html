江氏小六壬核心元素與推演教學手冊

1. 正確推演起卦步驟

  • 大安起月：從 1(大安) 數起，按 大安 → 留戀 → 速喜 → 赤口 → 小吉 → 空亡 順數月數，求得「月建落宮」。
  • 月上起日：以「月建落宮」為初一，順數日數，求得「日建落宮」。
  • 日上起時（定自身）：以「日建落宮」為子時(1)，順數時辰數，求得「時辰落宮」。時辰落宮即為「自身」（身宮），代表問事者的現況與主體。

2. 十二時辰與陰陽跳辰機制

十二地支無法直接塞進六個宮位，因此本派採用「陰陽分治、隔位跳辰」法。以問事時辰歸屬決定全盤地支：

時辰分類 涵蓋地支與數值 六宮排盤流轉方式
陽支盤 子(1)、寅(3)、辰(5)、午(7)、申(9)、戌(11) 以時辰所在陽支為基準，由身宮起順時針每宮跳一辰環排（例如：午 → 申 → 戌 → 子 → 寅 → 辰）。
陰支盤 丑(2)、卯(4)、巳(6)、未(8)、酉(10)、亥(12) 以時辰所在陰支為基準，由身宮起順時針每宮跳一辰環排（例如：未 → 酉 → 亥 → 丑 → 卯 → 巳）。

4. 六親生剋法則（以自身為立極點）

以時辰落宮（身宮）所落的地支五行為「我」，比對其餘各宮地支五行：

  • 生我者為【父母】：代表文書、印綬、長輩、房產、考試面試憑證、車輛機票。
  • 我生者為【子孫】：代表福德、解厄、解災、醫藥、晚輩、產品獲利來源。
  • 克我者為【官鬼】：代表功名、職位、官司、壓力、病魔阻礙、女占夫星。
  • 我克者為【妻財】：代表錢財、利潤、伴侶、商業交易、男占妻星、貴重遺失物。
  • 同我者為【兄弟】：代表同儕、合夥人、同輩競爭者、分財劫財、官司原被告。
